# Catalog v2 vectors

Shared test vectors of the signed widget catalog v2, documented in
[`docs/widget-catalog-v2.md`](../../../../docs/widget-catalog-v2.md). The
crate's `tests/catalog_v2.rs` replays all of them; the creator portal and
the catalog tooling replay the same files.

## Signed catalogs: `valid/` and `invalid/`

Generated by `tests/catalog_v2_gen/mod.rs`; never edit them by hand.
Regenerate after a format change with
`cargo run -p overcrow-widget-schema --example fixtures`; the test fails if
a committed file differs from the generator's output.

Every file is a catalog v2 envelope signed with the public conformance key
`overcrow-widgets-conformance` (public key:
[`../conformance-key.pub`](../conformance-key.pub), lowercase hex; its
private seed is the SHA-256 of the public string `OverCrow widget
conformance key; never trusted`). No production key signs a vector.

Replay a file the way an application reads the catalog:

1. open the envelope (`formatVersion` 2, exact fields);
2. trust only the conformance key: any other `keyId` fails with
   `key_unknown`;
3. verify the Ed25519 signature over `OverCrow widget catalog v2`, one NUL
   byte, then the payload bytes;
4. validate the payload at `2026-10-01T00:00:00Z` (Unix 1790812800) for the
   production origin (`https://overcrow.playervox.com/marketplace/widgets/v2/`).

A file in `valid/` passes. A file in `invalid/` is named
`<code>--<case>.json` and fails with exactly `<code>`, the
`CatalogV2Error::as_str` value (or `key_unknown`, `signature`).

| Valid vector | What it shows |
| --- | --- |
| `full` | three publishers (`playervox` with `playervox.com`, `example-labs` with `example.com`, `nightowl` without a domain), a built-in widget with a preview, a closed-source widget using the network with games and a privacy policy, a handle-owned widget under `MIT OR Apache-2.0`; four versions, one revoked, one with release notes |
| `empty` | categories only |
| `new-category` | a category absent from the initial list, used by a widget |
| `spdx-expression` | `GPL-3.0-or-later WITH Classpath-exception-2.0` |
| `suspended-built-in` | a built-in version under `security-suspended` |
| `unknown-members` | unknown keys at every level of the payload, ignored: same result as `full` |
| `requires-widget` | a widget whose `requires` names an unknown feature, skipped with its version (a newer manifest, unread): same result as `full` |
| `requires-target` | a version whose `requires` names an unknown feature, skipped: same result as `full` |
| `requires-malformed` | a widget whose `requires` is malformed (a name with a space, a dotted name), skipped with its version rather than refusing the catalog |

The listed versions of `full` are real packages built from
`../package-src/` (`clock`, `weather` at 2.2.0 and 2.3.0-beta.1, `minimal`
as `nightowl.focus`); the archives are not committed.

## Listing fields: `fields.json`

Hand-written. `cases`: `{ "field", "value", "valid" }`, where `field` is:

| `field` | Rule |
| --- | --- |
| `publisherName` | display text, one line, at most 64 characters |
| `description` | display text, line feeds allowed, at most 500 characters |
| `categoryLabel` | display text, one line, at most 32 characters |
| `gameName` | display text, one line, at most 100 characters |
| `link` | a listing link |
| `email` | a support address |
| `spdxLicense` | a simple SPDX expression or `LicenseRef-Proprietary` |

Characters are Unicode scalar values. Strings use JSON escapes for the
invisible characters they test.
